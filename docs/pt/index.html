Jogue Dofus multiconta no Mac sem brigar com as janelas.

O Multi-Tofu troca entre seus clientes do Dofus com uma tecla só. Ele lê cada janela e coloca o personagem certo na frente, acabou a caça no Mission Control no meio do combate.

Baixar para macOS Ver o código

Grátis e open source. Apple Silicon e Intel. Versão 0.2.0.

O que faz

Troca instantânea

F1 e F2 percorrem sua rotação, F3 volta direto para o líder. Uma tecla, sem mouse, sem Mission Control.

Roda de personagens

Segure Option e uma roda aparece no cursor com o ícone de classe de cada personagem. Mova, solte, aquele cliente vem para a frente.

Times

Divida seus personagens em times e gire só dentro do ativo. Útil quando você monta uma dungeon e deixa o resto parado.

Teclas diretas

Uma tecla fixa por personagem. F5 sempre vai no seu Iop, faça o que fizer a rotação.

Nomes reais

Os nomes são lidos ao vivo na janela do jogo. Nada para digitar, nada para manter.

Quatro idiomas

Inglês, francês, espanhol e português, seguindo o idioma do seu sistema.

Ele reconhece seus personagens sozinho

Você nunca digita um nome. O Multi-Tofu lê o título da janela do Dofus, então assim que um personagem entra o nome real dele aparece na roda, na barra de menus e nos ajustes. Um cliente aberto mas ainda na tela de login não tem personagem, então aparece como Conta 1, Conta 2 e assim por diante. Eles continuam clicáveis no menu, você pode ir lá fazer login, mas ficam fora da rotação do F1. Uma tecla nunca leva você para uma janela sem personagem.

Instalação em um minuto

Baixar e descompactar

Pegue o zip na página de versões e arraste o Multi-Tofu para a pasta Aplicativos.

Botão direito, Abrir

O app não é assinado com uma conta paga de desenvolvedor da Apple, então a primeira abertura precisa de botão direito e Abrir. Depois disso abre normalmente.

Permitir Acessibilidade

O macOS pede uma vez. O Multi-Tofu precisa dela para ler os títulos das janelas e ouvir seus atalhos. Ative e os atalhos ligam alguns segundos depois, sem reiniciar.

Atalhos padrão

Próximo personagemF1
Personagem anteriorF2
Ir para o líderF3
Procurar janelasF4
Roda de personagenssegurar Option
Abrir ajustesControl + F1

Tudo pode ser remapeado. Os atalhos são gravados como códigos de tecla física, então continuam funcionando se você trocar entre AZERTY e QWERTY.

Não automatiza nada

O Multi-Tofu traz janelas para a frente. É só isso que ele faz. Não tem bot, não lê pacotes, não injeta memória e não transmite uma tecla para vários clientes ao mesmo tempo. Toda ação continua vindo de você, em um cliente por vez. O código é público, você não precisa acreditar na nossa palavra.

Por que existe

No Windows existem o Dosoft e o Organizer. No Mac não existia nada, e o projeto mais próximo foi arquivado em agosto de 2026. O Dosoft é Apache 2.0 mas construído inteiramente sobre a API Win32, então nada dá para portar. Esta é uma implementação nova sobre a API de Acessibilidade do macOS, um CGEventTap para os atalhos e o AppKit para a roda, reaproveitando a arte das classes e o design funcional sob aquela licença.

Requisitos

  • macOS 12 ou mais recente
  • Dofus 3 (Unity), o cliente que o Ankama Launcher instala
  • Apple Silicon ou Intel, uma única build universal
  • Modo janela ou sem borda, a roda não desenha sobre tela cheia exclusiva
